# 과제 1. 주문 처리 콘솔 앱

위키 실습 과제의 **모범 답안 프로젝트**입니다. 과제 페이지의 코드 블록만으로 새로 만들어 빌드·테스트·H2 실행까지 검증한 결과물(2026-09-28)입니다.

- 과제 페이지: https://wiki.wonslab.dev/guide-java-practice-core
- 패키지: `dev.wonslab`
- 실행: `mvn test && mvn -q compile exec:java -Dexec.mainClass=dev.wonslab.practice.core.OrderApp`

이 브랜치는 기존 코드(main)와 독립적인 실습 자료이며, main에는 영향을 주지 않습니다.
